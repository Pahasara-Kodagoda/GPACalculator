# 🎓 GPA Calculator System

A lightweight and intuitive **Windows Forms Desktop Application** developed in **C# / .NET** to help university students track, manage, and calculate their semester GPAs and Cumulative GPA (CGPA) effortlessly.

---

## ✨ Features

- 📊 **Semester GPA Calculation:** Easily compute GPA for individual semesters based on course credits and grades.
- 🎯 **Cumulative GPA (CGPA):** Track your overall academic progress across multiple semesters.
- ➕ **Dynamic Course Management:** Add, edit, or remove courses and credit values dynamically.
- 💻 **Clean & User-Friendly UI:** Simple desktop interface designed for quick navigation and fast entries.

---

## 🛠️ Built With

- **Language:** C#
- **Framework:** .NET Framework / .NET (Windows Forms)
- **Database / Storage:** SQLite / Local File Storage 
- **IDE:** Visual Studio
